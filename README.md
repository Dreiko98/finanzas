# Finanzas

Aplicación personal y deliberadamente sencilla para revisar semanalmente el plan financiero.

## Requisitos

- PHP 8.1 o superior con PDO y `pdo_sqlite` (o `pdo_mysql`).
- Apache con `mod_rewrite` en producción.

La instalación y el despliegue se documentarán al completar los módulos funcionales.
